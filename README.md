# Student-Data-Management-System
Description:
A simple C++ program for managing student records, including adding, displaying, searching, updating, and deleting student information (name, roll number, course, class, and contact).

Features:
Enter Data: Add student records.

Show Data: View all student records.

Search Data: Find a student by roll number.

Update Data: Modify student details.

Delete Data: Remove specific or all records.

Exit: Close the program.

How to Use:
Select an option (1-6) to perform corresponding actions.

Enter student details when prompted.
